# Source note

## Supports

The review establishes expert judgment as an important and extensively studied estimation practice in software engineering, particularly for development effort. It provides domain context for comparing collective probabilistic evidence with an accountable engineering owner's judgment rather than treating formal models as the only meaningful reference.

## Does not support

Effort estimation is not the same target as qualification, integration or release-outcome forecasting. The review does not validate the Forecast Contract, the meta-prediction aggregator or any Study 0 effect size.
