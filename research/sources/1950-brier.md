# Source note

## Supports
The Brier score evaluates probabilistic forecasts against realized outcomes. For a binary two-category vector, the original summed index is twice the normalized one-component loss used by this repository.

## Does not support
One event or one lower score does not establish that a forecasting method is generally superior.
