# Source note

## Supports
Howard describes the clarity test as part of disciplined decision analysis: uncertain distinctions should be formulated so that one knows what is being discussed and how uncertainty can be resolved. This is a conceptual ancestor for the Forecast Contract's resolvability requirement.

## Does not support
Howard does not define this repository's Forecast Contract or its engineering schema.
